# Frontend Development Rules

Triggered when:

- Editing files in `frontend/` directory (Next.js)

## Skills Triggered

The following skills should be loaded and consulted:

- `devup-ui`: For styling and component usage. Zero-runtime CSS-in-JS.
- `devup-api`: For API client generation and type-safe data fetching.
- `docker-master`: When touching Dockerfile or environment configs.
