# Frontend Rules & Conventions (Devup UI/API)

This directory uses `devup-ui` for styling and `devup-api` for data fetching. Strict adherence to the following conventions is required.

## Styling (Devup UI)

**CORE PRINCIPLE**: Zero Runtime. All styles must be extracted at build time.

### ✅ DO

- Use **Shorthand Props** always: `bg`, `p`, `m`, `w`, `h`.
- Use **`$` Prefix** for theme colors: `bg="$primary"`.
- Use **Responsive Arrays** for breakpoints: `w={["100%", "50%"]}`.
- Use **`_underscore`** for pseudo-states: `_hover={{ bg: "..." }}`.
- Use **`Box as={Component}`** for dynamic values on custom components.

### ❌ DO NOT

- **NEVER** use `style={{ ... }}` prop (It bypasses the compiler).
- **NEVER** use full prop names like `backgroundColor` or `paddingTop` (Use shorthands).
- **NEVER** use `css()` for dynamic values (It only accepts static objects).
- **NEVER** use `as any` or `@ts-ignore` on style props.

## Data Fetching (Devup API)

### ✅ DO

- Use **`createApi`** to generate the client.
- Use **`DevupObject`** for type definitions (Avoid manual interfaces).
- Use **`react-query`** hooks generated by `createApi` when possible.

## Project Structure

- `app/` - Next.js App Router pages
- `df/` - Generated type definitions (DO NOT EDIT)
- `devup.json` - Theme configuration
